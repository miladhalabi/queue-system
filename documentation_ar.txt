نظام إدارة الطوابير (QueueFlow) - التوثيق الفني والوظيفي

١. نظرة عامة على النظام:
نظام متكامل لإدارة الطوابير في الوقت الفعلي، يدعم اللغتين العربية والإنجليزية، ويتيح الانضمام عبر الويب أو بوت تيليجرام مع لوحة تحكم متطورة للمسؤولين.

٢. الوظائف الحالية:

أ. مميزات العملاء:
- الانضمام للطابور عبر الويب: واجهة بسيطة وسريعة لإصدار التذاكر.
- بوت تيليجرام: انضمام فوري باستخدام اسم تيليجرام، مع إمكانية ذكر سبب الزيارة.
- تتبع الدور في الوقت الفعلي: تحديث تلقائي للموقع في الطابور عبر WebSockets.
- دعم اللغات: تبديل فوري بين العربية والإنجليزية مع دعم كامل لاتجاه النص (RTL).
- إشعارات ذكية: تنبيه العميل عبر تيليجرام عندما يصبح "التالي" وعند مناداته.
- الحفاظ على الجلسة: بقاء العميل في الطابور حتى عند إغلاق المتصفح.

ب. مميزات المسؤولين:
- لوحة تحكم مؤمنة: حماية كاملة باستخدام رمز التشفير (JWT).
- إدارة الطابور: مناداة العميل التالي، تخطي العملاء مع ذكر السبب.
- سجل التذاكر: عرض كامل للعمليات السابقة (تمت خدمته، تم تخطيه، غادر).
- إعدادات النظام: إمكانية تفعيل أو تعطيل إلزامية ذكر سبب الزيارة عند الانضمام.
- إحصائيات مباشرة: متابعة أعداد المنتظرين ومن تمت خدمتهم خلال اليوم.

ج. الجوانب التقنية:
- الواجهة الأمامية: React 19, Tailwind CSS 4, Zustand.
- الواجهة الخلفية: Node.js, Express, Prisma ORM, Socket.IO.
- قاعدة البيانات: PostgreSQL.

٣. التحسينات والتحديثات المستقبلية:

أ. التكامل مع الأنظمة التجارية (كأنظمة البنوك):
- الربط مع أجهزة Kiosk: إصدار تذاكر ورقية وربطها بالرقم الرقمي.
- نظام المحولات (Adapter Layer): دعم الربط مع أنظمة مثل Qmatic عبر REST API.
- توزيع الكاونترات: إمكانية توجيه العميل إلى رقم كاونتر محدد (مثلاً: توجه إلى كاونتر رقم ٤).

ب. تجربة الانتظار في الموقع:
- شاشة العرض العامة (TV Display): واجهة مخصصة للشاشات الكبيرة في صالات الانتظار.
- التنبيه الصوتي: استخدام تقنية تحويل النص إلى صوت (TTS) لمناداة الأرقام بالعربية والإنجليزية.
- مولد رموز QR: طباعة رمز QR يسهل على العملاء الانضمام بمجرد المسح.

ج. ذكاء الأعمال والتقارير:
- لوحة تحليل البيانات: رسوم بيانية توضح أوقات الذروة ومتوسط وقت الانتظار.
- تقارير الأداء: قياس سرعة خدمة الموظفين وكفاءة التعامل مع التذاكر.

د. تحسينات تقنية إضافية:
- تطبيق PWA: إمكانية تثبيت النظام على الهواتف كأنه تطبيق أصلي.
- استخدام Redis: لزيادة قدرة النظام على التعامل مع آلاف المستخدمين في آن واحد.
- التنبيهات الخارجية: دعم إرسال رسائل عبر WhatsApp أو SMS.
